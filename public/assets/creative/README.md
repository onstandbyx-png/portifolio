# Assets do estudo visual

Criados para a evolução do portfólio Ideia ↗ Execução em 15/10/2026. O estudo principal é **LINHA**, produto fictício de revisão e aprovação criativa. As peças conectam um problema reconhecível — confusão entre versões — à proposta “Do briefing ao aprovado. No mesmo lugar.”

| Arquivo | Dimensão | Aplicação |
| --- | --- | --- |
| `hero-editorial.svg` | 1000 × 600 | Composição editorial “Histórias que ficam.”; área segura para corte central em 3:2. Estudo visual, sem vínculo ou atribuição de trabalho a clientes. |
| `linha-interface.svg` | 1200 × 900 | Interface ilustrativa do LINHA: briefing, revisão, aprovado; versão v03 com um comentário aplicável. |
| `linha-campanha.svg` | 1200 × 1500 | Campanha conceito do LINHA: “Qual arquivo é o final_final?”, pilha de versões e convite para explorar o fluxo. |
| `direcao-editorial.svg` | 1200 × 1500 | Prancha de direção editorial, tipografia e composição. |
| `narrativa.svg` | 1200 × 1500 | Prancha de arquitetura narrativa em três momentos. |
| `sistemas.svg` | 1200 × 1500 | Prancha de intenção, lógica e experiência digital. |
| `og-cover.png` / `og-cover.svg` | 1200 × 630 | Capa social de Smile N, renderizada a partir de composição vetorial original. |

LINHA é um produto conceito, não uma plataforma comercial publicada, cliente ou promessa de funcionalidade já lançada. As interfaces são ilustrativas e não contêm números de desempenho. Preservar a identificação “produto conceito” ou “estudo autoral” quando apresentado ao público.

As pranchas são composições vetoriais de estudo. Todo este material representa exploração conceitual feita para o portfólio. Não é trabalho publicado para cliente, nem evidencia resultados comerciais.

Os SVGs têm título, descrição e o rótulo visível “ESTUDO AUTORAL”. Para interfaces, apresentar qualquer texto essencial também em HTML.

Paleta: papel `#f6f6f2`, tinta `#16221c`, verde `#274b38`, cobre `#bc6748`.

A fonte `symbols.ttf` contém somente os glifos de interface utilizados, extraídos de DejaVu Sans. Licença e créditos completos em `SYMBOLS-LICENSE.txt`.
